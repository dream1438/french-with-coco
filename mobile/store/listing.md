## Google Play: Data safety answers
- Collects data: **Yes** (only with an optional account).
  - Personal info → Email address, Name: collected, not shared, optional, purpose "Account management", encrypted in transit, users can request deletion.
  - App activity → Other actions (course progress): collected, not shared, optional, "App functionality", "Account management".
- Data shared with third parties: **No**. Ads: **No**. Data encrypted in transit: **Yes**. Account deletion URL: https://languageswithcoco.com/delete-account/
- Target audience: 13+ (all ages can use it, but the account/email features are not built for young children). Contains ads: No.

## App Store: App Privacy answers
- Data linked to the user (only with an account): Contact Info → Email Address, Name; User Content/Usage → course progress ("Other Usage Data"). Purpose: App Functionality. Not used for tracking.
- Tracking: **No**.
- Sign in with Apple: required before release because Google sign-in is offered.
- Review notes: "Accounts are optional; reviewers can use every lesson without signing in. Account deletion: account button → Delete my account."
