# Coco web app plan (2026-11-21)
1. **v1 (now, A1 only):** static responsive site. Lessons in order with YouTube embeds, worksheets (Drive), quizzes from the lesson scripts, progress on the device, Arabic mode. Preview locally, owner feedback.
2. **v2:** all levels (A2–C1 data from the same scripts as videos go live), Arabic meanings checked by the owner, search, flashcard review of past words, installable on phones (PWA, works offline).
3. **Go public (owner decides):** free static hosting (GitHub Pages / Cloudflare Pages) + optional domain; link from YouTube descriptions.
4. **Later:** sign-in to sync progress, paid extras (practice packs, certificates of completion, live classes) with a payment provider. Needs owner decisions on price and provider.
